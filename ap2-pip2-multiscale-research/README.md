# AP2–PIP₂：膜环境中的分子互作、构象调控与多尺度研究设计

*AP2–PIP2 Interactions: Membrane Context, Conformational Regulation, and Multiscale Research Design*

这是一份围绕具体案例学习研究设计的材料。它从 AP2 为什么结合含 PIP₂ 的膜出发，继续讨论构象、驻留、clathrin 装配和细胞内吞，重点放在每一轮实验为什么这样选，以及不同结果出来后怎样继续。

## 可以怎样学

初次阅读可先看主案例的第3章，顺着论文里的实验选择往下走，再看第6章怎样把膜招募与构象变化分开。已经有实验现象时，第9章提供六种结果情境；准备课题时，第11章可用来安排第一轮工作。

动态成像专题适合接着主案例读：连续追同一对象、SIM在单个时间点的重构、分时冻结的结构序列，各给出不同的时间信息。随后再回到AP2，选择到达率、驻留、等待时间或结构群体这些分析对象。

建议把自己的构建体、膜配方、货物和测量条件带进来。每读完一个实验选择，试着回答：换成我的条件，哪一项比较还成立，下一步最想知道什么？

## 内容与定位

主案例有15章、16篇原始研究引用，包含1幅Kovtun 2020论文原图；动态成像专题另有5条来源，其中2篇与主案例重合。文献包括Cell、Science、Nature及相关领域期刊。
