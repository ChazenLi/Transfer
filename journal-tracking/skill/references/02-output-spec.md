# 02 · 输出规范 · 口径声明 · 质检清单

---

## 一、每条论文的标准字段

缺任何一项都要标注原因，**不得留空不留痕**。

### 1.1 身份字段（必填）

| 字段 | 要求 |
|---|---|
| 中文题名 | 有官方中文题名则用，否则自译并在报告里说明"题名自译" |
| 英文原题 | 原样照抄，不改写 |
| 作者 / 通讯单位 | 通讯作者全名 + 机构；大型合作组写合作组名（如 GRAVITY Collaboration） |
| 发表日期 | 统一用在线发表日期，ISO 格式 |
| 栏目 | Article / Review / Report / Resource …（用于后续过滤） |
| DOI | 完整可点击 |
| 标签 | 2–4 个主题/方法标签（可选，卡片式报告可省） |

### 1.2 内容字段 —— **四层深读结构（默认）**

> **核心原则：报告的价值不在"发了什么"，而在"为什么必须这么做、以及为什么这么做能成立"。**
> 只写结论的卡片是检索工具，不是阅读材料——它不产生思考。默认按下面四层写。

| 层 | 名称 | 要回答的问题 | 写作要求 |
|---|---|---|---|
| 1 | **问题** | 这篇要攻的卡点是什么？**上一代方案为什么不够？** | 2–3 句。必须点出"卡在哪"，而不只是"研究 X"。这一层决定读者能否迁移联想 |
| 2 | **手段** | 实际用了什么技术 / 实验体系 / 模型 / 队列？ | 点名具体方法，带关键量级（样本量、参数范围、灵敏度）。写"用了什么"而非"研究了什么" |
| 3 | **机理** ★ | **为什么这个手段能绕过那个卡点？** | 本次新增的核心层。必须是**因果链**（A 改变 → 导致 B → 所以 C 成立），不是背景知识堆砌。1–3 句，一句话直觉 + 半句机制 |
| 4 | **结论** | 带数字的结果 + 成立条件与边界 | 3–5 条，**必须带具体数字**。同时写"不适用/未验证"的边界 |

**机理层的三条纪律（重要）：**

1. **必须标注性质。** 问题/手段/结论来自论文材料；**机理层是解释性归纳**——基于摘要 + 学科通用原理由助手重建的因果链，**不等于作者原话**。报告口径声明中必须写明这一点，避免被当作原文引用。
2. **不做术语搬运。** 判断标准：读完这一层，读者能否说出"如果换掉这个设计，事情会怎样失败"。说不出就是没写到机理。
3. **不确定就降级。** 若材料不足以支撑因果链（只有标题、无摘要），写成"机理未展开（材料不足）"，**不要编**。

**反例 vs 正例**

| | 写法 |
|---|---|
| ❌ 反例（结论罗列） | "开发了 RADAR 模型，在 40 万例 CT 上训练，覆盖 18 结构，辅助医生敏感度提升 10%" |
| ✅ 正例（含机理） | "**问题**：有监督学习要求医生逐张标注病灶，成本极高且模型只会认标注过的征象。**机理**：临床报告本身就描述了图里有什么，等于一份免费且覆盖罕见征象的监督信号；图文对比预训练学的是'视觉模式↔语言描述'的通用映射而非固定类别列表，所以对未见异常也能靠语言侧语义泛化。" |

### 1.3 深度分层策略（防止报告变成不可读的长文）

四层结构很重，**不要无差别地给每一篇都写满**。按下面分级：

| 级别 | 适用 | 处理 |
|---|---|---|
| **深读卡** | **全部研究论文（默认档位，用户已确认）** | 完整四层 |
| **紧凑卡** | 仅当论文数极多且用户明确要求压缩时的次级内容 | 问题 + 手段 + 结论（可省机理，或机理压到一句） |
| **表格行** | 子刊汇总、新闻/评论/社论/勘误 | 表格；**勘误与撤稿绝不进研究论文段** |

> **不要自行降级。** 实测单期 29 篇全部四层 ≈ 69 KB / 1,100 行 HTML，仍然可读。用户要的是能产生深入思考的深度，**篇幅不是约束条件**。想降级必须先问。

**周报至少要有一节"贯穿本期的方法学主线"**——把各篇的机理层横着读，提炼 2–4 个反复出现的解题动作（例如"换观测量"、"解耦维持与运算"、"去掉最贵的监督成本"、"推翻默认假设"）。这一节是四层结构真正的产出物，也是最能产生迁移性思考的部分。

> 最常见的问题是"关键发现"被写成摘要的中文缩写，或四层只写了结论层。**要求是：读者只看这几条就能判断这篇值不值得读，并且知道它的方法能迁移到哪里。**

## 二、报告结构（周报模板）

```
1. 头部：统计窗口（起止日期）+ 对应卷期 + 生成时间 + 来源声明
2. 概览指标：研究论文数 / 在线优先数 / 子刊重点数 / 上线高峰日
3. 【图例】怎么读这四层 —— 简述 问题/手段/机理/结论 各层在说什么（首次交付或格式变更时给）
4. 正刊本期（按学科分组，四层深读卡片）
5. 正刊在线优先（AOP）—— 同样按四层写
6. 系列子刊重点（表格，按 问题→机理→结论 压缩成一行）
7. ★ 贯穿本期的方法学主线 —— 横向提炼 2–4 个反复出现的"解题动作"，每条约 3–4 句
8. 口径与说明（见下）
```

> 第 7 节是**必写项**，不是可选装饰。四层结构写完之后，如果没能从里面提炼出可迁移的方法学模式，说明机理层写得不够到底。

## 三、口径声明模板（**必写，不可省**）

```markdown
**口径与说明**
· 统计窗口为 YYYY-MM-DD 至 YYYY-MM-DD。〈刊名〉为〈出版节奏〉，该窗口对应 Vol X, Issue Y（YYYY-MM-DD）。
· 数据来源：〈列出实际用到的 Layer 0/1/3/4 源〉。〈若某源对本刊滞后，必须写明，如 "Europe PMC 对本刊本周返回 0 条，故主干为 eTOC RSS"〉。
· 【若为高亮非全量】第 N 节的条目来自〈来源〉的导读/高亮覆盖，**非该期全量目次**。全量需以 Europe PMC 枚举为准。
· ⚠️ **关于"机理"层的性质**：问题 / 手段 / 结论三层取自论文的编辑摘要或原文摘要；**"机理"层是解释性归纳**——基于上述材料与学科通用原理重建的因果链，服务于理解"为什么这样能成立"，**不等于作者原始表述，不应作为原文引用**。如需引用机制请回原文核对。
· 子刊条目部分来自机构新闻稿与二次报道，日期与结论以各刊官网最终版本为准。
· 标注"待核实"的条目，尚未确认 DOI 或正式期次。
· 边界情况：〈落在窗口外一天但相关的论文，单独说明〉。
· 方向性说明：AI 摘要中的结论性判断为助手归纳，非论文作者表述。
```

> **机理层的免责声明是硬性要求。** 四层结构里只有这一层是重建出来的内容，不标明性质就存在被误读为原文的风险。

## 四、质检清单（交付前逐项过）

- [ ] 窗口起止日期明确写出
- [ ] 卷期换算已核对（不是猜的）
- [ ] 新闻/社论/评论/Correspondence/Preview **已剔除**出研究论文
- [ ] **Correction / Erratum / Retraction 未混入**新论文
- [ ] 每条都有 DOI，或明确标注"待核实"
- [ ] **每篇研究论文都写了"问题"层**——点出了上一代方案卡在哪，而非只说"研究了 X"
- [ ] **"手段"层点名了具体技术/模型/队列，并带关键量级**
- [ ] **"机理"层写成了因果链**（A→B→C），不是背景知识或术语罗列；抽查法：能否说出"换掉这个设计会怎样失败"
- [ ] **机理层的性质已在口径声明中标注**（解释性归纳，非作者原话）
- [ ] 材料不足以写机理的条目，**写明"机理未展开（材料不足）"而非编造**
- [ ] 结论带具体数字，非摘要翻译
- [ ] 每条（或至少每篇深读卡）写了**边界/局限**，不只是正面结果
- [ ] **有一节"贯穿本期的方法学主线"**，且提炼出的动作可迁移（不是复述各篇结论）
- [ ] 中文来源的数字已与英文原文核对（**警惕中文导读笔误**）
- [ ] 凡"高亮非全量"的情况已在口径声明中写明
- [ ] 窗口边界外的论文已单独说明，未悄悄计入
- [ ] 未编造任何 DOI / 卷期 / 页码 / 作者 / 机制
- [ ] 若引用 Altmetric 等热度指标，已注明"关注度 ≠ 学术重要性"
- [ ] **HTML 交付物已做标签平衡校验**：统计 `<div>`/`</div>`、`<section>`/`</section>` 是否配对，并统计卡片数是否等于目标篇数
- [ ] ⚠️ 校验时**必须显式指定 UTF-8 读取**：PowerShell 5.1 的 `Get-Content` 默认按 GBK 解码 UTF-8 文件，会把中文行末尾的 `<` 吞掉，制造"标签少一个"的**假警报**，进而去"修"一个本来没坏的文件。正确写法：`Get-Content $f -Raw -Encoding UTF8`
- [ ] 交付物已用 `present_files` 呈现

## 五、交付物规范

- **默认**：单文件 HTML 周报，自包含（不依赖外部 CDN/字体），浅色主题，可离线打开
- **放置**：工作区根目录；**一手素材放 `data/`**（见 `00-workflow.md` Step 6.1）
- **命名**：`<刊名缩写>-weekly-YYYY-MM-DD.html`，日期取窗口起始日
  - 四层深读版加 `-deep` 后缀，如 `nature-weekly-2026-09-14-deep.html`，便于与三段式旧版区分
- **版本管理**：被新版取代的旧交付物**移入 `archive/`**——不要留在根目录，也不要直接删除
  （保留是为了对照口径差异，例如"高亮抽样版 vs 全量枚举版"）
- **分段撰写**：四层深读版单文件可达 **90+ KB / 1,100+ 行**，一次性 Write **有中断风险**（实测中断 2 次）。
  建议按学科节分段追加；中断后先做结构校验、定位断点再续写，**不要重写整个文件**。
- **交互**：卡片式，按学科分组；表格用于子刊汇总；文末固定放口径声明
- **最后一轮工具调用必须是 `present_files`**

## 六、措辞禁忌

| 不要写 | 改写成 |
|---|---|
| "该期共发表 N 篇论文"（当实际只有高亮） | "该期 N 篇进入主流导读视野"/"枚举得到 N 篇研究论文" |
| "这是重大突破" | 陈述证据强度："作者称是迄今最低的面积放大损失" |
| "中国科学家主导"（未核实） | 列出具体通讯作者与机构，让读者自己判断 |
| 引用数排序 | 窗口内引用数必然为 0，改用 Altmetric 并注明局限 |
